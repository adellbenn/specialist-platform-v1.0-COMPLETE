## 👥 نظام الأدوار والصلاحيات (RBAC)

### الأدوار النشطة (Active)

#### 1. 🔐 Super Admin
- **الصلاحيات:** جميع الصلاحيات
- **الوصول:** النظام بأكمله
- **الحالة:** ✅ مفعّل

#### 2. 👔 Center Manager
- **الصلاحيات:** إدارة المركز كاملاً
- **الوصول:** لوحة تحكم + إدارة المستفيدين + المواعيد + الجلسات + التقارير
- **الحالة:** ✅ مفعّل

#### 3. 👨‍💼 Supervisor
- **الصلاحيات:** مراقبة + موافقة التقارير
- **الوصول:** عرض فقط + موافقة التقارير
- **الحالة:** ✅ مفعّل

#### 4. 👨‍⚕️ Specialist
- **الصلاحيات:** إدارة حالاته الخاصة
- **الوصول:** المستفيدون (خاصته) + المواعيد + الجلسات + التقارير (خاصته)
- **الحالة:** ✅ مفعّل

#### 5. 📞 Receptionist
- **الصلاحيات:** إدارة المستقبلة
- **الوصول:** المستفيدون + المواعيد + الإشعارات
- **الحالة:** ✅ مفعّل

#### 6. 👤 Beneficiary
- **الصلاحيات:** عرض بيانات نفسه
- **الوصول:** بيانات شخصية + المواعيد (الخاصة) + التقارير (المشاركة)
- **الحالة:** ✅ مفعّل

### الأدوار المعطّلة (Disabled - للمستقبل)

#### ❌ Accountant (معطّل)
- **الصلاحيات:** موجودة لكن غير مفعّلة
- **السبب:** سيتم تفعيله في مرحلة لاحقة
- **الحالة:** ⏸️ معطّل مؤقتاً
- **ملاحظة:** يمكن تفعيله بسهولة بدون فقدان البيانات
