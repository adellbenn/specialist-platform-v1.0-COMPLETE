# 🚀 QUICK_START.md

## ابدأ الآن في 5 دقائق!
**Get Started in 5 Minutes!**

---

## 1️⃣ فك الضغط (Unzip)

```bash
unzip specialist-platform-complete.zip
cd specialist-platform
```

---

## 2️⃣ ثبّت الـ Packages (Install)

```bash
npm install
```

---

## 3️⃣ شغّل Backend (Terminal 1)

```bash
cd apps/backend
npm run start:dev
```

**انتظر حتى ترى:**
```
✅ Nest application successfully started on port 3001
```

---

## 4️⃣ شغّل Frontend (Terminal 2)

```bash
cd apps/frontend
npm run dev
```

**انتظر حتى ترى:**
```
✅ ready - started server on 0.0.0.0:3000
```

---

## 5️⃣ سجّل الدخول (Login)

```
الرابط: http://localhost:3000

البريد: admin@platform.com
كلمة المرور: Admin@123456
```
